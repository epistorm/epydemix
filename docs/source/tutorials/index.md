# Tutorials

Twelve worked notebooks. They are shown here with their saved outputs; each has an
**Open in Colab** button at the top if you want to run it yourself, and the sources are
in the [tutorials folder on GitHub](https://github.com/epistorm/epydemix/tree/main/tutorials).

**Getting started**

1. {doc}`01_Model_Definition_and_Simulation`: define a model and run simulations
2. {doc}`02_Modeling_with_Population_Data`: real populations and contact matrices
3. {doc}`03_Modeling_Interventions`: non-pharmaceutical interventions

**Calibration**

4. {doc}`04_Model_Calibration_part1`: fitting a model to data with ABC
5. {doc}`05_Model_Calibration_part2`: more on ABC calibration and projections

**Going further**

6. {doc}`06_Advanced_Modeling_Features`: custom transition rules and other advanced features
7. {doc}`07_Covid-19_Example`: the first wave of COVID-19 in Massachusetts
8. {doc}`08_Multiple_Strains`: models with several strains
9. {doc}`09_Vaccinations`: a vaccination rollout
10. {doc}`10_Multiprocessing`: speeding up simulations and calibration
11. {doc}`11_Epistorm_Mix_Matrices`: contact matrices by sex and race/ethnicity
12. {doc}`12_Predefined_Models`: predefined models and their modular extensions
